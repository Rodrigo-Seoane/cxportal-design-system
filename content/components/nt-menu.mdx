## Overview

CxPortal's left/vertical navigation, replacing the previous dark, full-width
sidebar (see the **Navigation** / **Nav Item** pages, now historical —
`nav-item.tsx` itself is kept only for that doc/playground, no longer
consumed by `Sidebar.tsx`) — a light-themed, rounded-pill tree menu with
drop shadows and connector lines between nested items, internally named
`MenuItemRow` / `MenuItemRowCollapsed` / `ModuleMenuGroup` in Figma.

**Wired into `Sidebar.tsx` as the live sidebar (2026-09-10).** It still has
**no Principles or Usage doc yet** in Figma — everything below is read
directly off the component nodes. Two props were added specifically for the
live-wiring pass, with no Figma state to confirm them against (see Open
questions): `href` on `NTMenuModuleItem`/`NTMenuSubItem`/`NTMenuItemCollapsed`
(renders a real `next/link` Link instead of a toggle button) and `showCaret`
on `NTMenuModuleItem` (hides the caret for a flat entry with no sub-items —
used for Sidebar's "Guidelines" link).

## Anatomy

- **`NTMenuHomeItem`** — the root "Home" row. `HouseIcon` + label + trailing
  caret. Pass `ancestor` to render it as a muted breadcrumb trail
  ("Home › {ancestor}") instead — Figma's "Nested" state.
- **`NTMenuModuleItem`** — a top-level, collapsible module row. `TreeViewIcon`
  (default) + label + caret, `CaretDownIcon` when `isOpen`.
- **`NTMenuSubItem`** — a nested child row. Leading elbow glyph + label, no
  icon slot.
- **`NTMenuGroup`** — composes an `NTMenuModuleItem` header with its
  `NTMenuSubItem` children, drawing the vertical trunk line that visually
  connects them.
- **`NTMenuItemCollapsed`** — icon-only pill for a collapsed sidebar state.
  Defaults to `HouseIcon`.

All rows are 220px wide, 36px tall (`max-height`), 8px radius, 12px padding.

## Code

### Basic group

```tsx
import { NTMenuGroup, NTMenuSubItem } from '@/components/ui/nt-menu'

<NTMenuGroup label="Global Permissions" open>
  <NTMenuSubItem label="Roles" state="active" />
  <NTMenuSubItem label="Users" />
  <NTMenuSubItem label="Companies" />
</NTMenuGroup>
```

### Home row + breadcrumb

```tsx
import { NTMenuHomeItem } from '@/components/ui/nt-menu'

<NTMenuHomeItem state="active" />

{/* Breadcrumb trail — display-only, matches Figma's "Nested" state */}
<NTMenuHomeItem ancestor="Admin" />
```

### Collapsed rail

```tsx
import { NTMenuItemCollapsed } from '@/components/ui/nt-menu'
import { GlobeIcon } from '@phosphor-icons/react'

<NTMenuItemCollapsed icon={<GlobeIcon size={13} />} state="active" />
```

## Open questions — not resolved

- **No Principles or Usage doc exists for this component in Figma yet** —
  everything on this page was read directly off the component nodes
  (`3660-6232` / `3869-13623` / `3660-6296`). The separate Navigation
  Principles/Usage pages (`735-30319` / `735-30339`) only cover the old dark
  sidebar family and don't mention this pattern at all.
- **The vertical trunk-line height is a formula, not a lookup table.**
  Figma hand-authors a distinct pixel height per sub-item count (28 / 73 /
  119 / 164 / 209px for 1–5 items) that doesn't reduce to one clean constant.
  Rather than hardcode five magic numbers, `NTMenuGroup` derives the line
  height from a single row-height constant, which visually approximates but
  does not pixel-match Figma's specific per-count values.
- ~~**Not wired into `Sidebar.tsx`.**~~ **Resolved (2026-09-10)** — see Overview.
- **The 3 specific Figma frames cited for this wiring pass weren't
  independently re-verified.** The user requested pulling collapsed-rail
  icons from node `3869-13623`, a collapsed alphabetical reference from
  `3919-57135`, and an expanded alphabetical reference from `3662-5909` —
  the Figma desktop plugin available in that session couldn't reach nodes
  outside whatever canvas was already open locally, and no other Figma
  access was available. The per-module icon set actually used is carried
  over unchanged from the previous dark-sidebar mapping (an established,
  already-approved assignment in this codebase — not freshly invented), not
  re-picked from `3869-13623`. Needs a visual check against those 3 frames
  once they're reachable.
- **`href` and `showCaret` props (on `NTMenuModuleItem`/`NTMenuSubItem`/
  `NTMenuItemCollapsed`) have no Figma state to confirm them against.**
  Added purely to support real `next/link` navigation and a flat
  no-sub-items entry ("Guidelines") when wiring this component into
  `Sidebar.tsx` — inferred from the wiring requirement, not from a Figma
  node.
- **No `disabled` state or deep-nesting (grandchild) pattern** is defined in
  the Figma nodes pulled so far — only what's listed above.
- **Status badges (stable/wip/deprecated), shown on Sidebar's previous
  dark-nav sub-items, were dropped** during the live-wiring pass per the
  user's explicit decision — `NTMenuSubItem` has no badge slot and none was
  added.
