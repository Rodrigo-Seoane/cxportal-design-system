## Overview

Page Title is the primary visual anchor for any content page. It displays the page name in a large blue heading alongside an optional subtitle and status chip. The right side is a composable slot where consumers can pass buttons, search bars, tabs, or any other page-level controls.

The component was simplified from three rigid variants to a single composable pattern. The previous `with-kb-details` variant is deprecated — KB metadata should be handled by a separate component if needed.

## When to use

- At the top of every content page to identify the current context.
- When a page represents a categorized or classified record — enable `showChip` to display a status label.
- When page-level actions (edit, delete) or controls (search, role tabs) need to be accessible from the header.

## When not to use

- Do not use Page Title for section headers within the page content. Use H3/H4 headings instead.
- Do not use in modals, drawers, or side panels.

## Anatomy

- **Title** — H2, 28px, weight 400, `#3a8015` (primary brand color). Always present.
- **Subtitle** *(optional)* — 12px, weight 400, `#373737`. Descriptive one-liner below the title.
- **Chip** *(optional)* — Info pill label. `#d6e2f5` background, 10px semibold text, border-radius 8px. Controlled by `showChip` prop.
- **Actions slot** *(optional)* — Right-aligned composable area. Consumers pass any ReactNode (ghost buttons, search inputs, tab groups, etc.).

## Do's & Don'ts

<DosDonts>
  <Do description="Keep the title to the page or record name — one to four words. Users scan it to confirm they're in the right place." />
  <Dont description="Put navigational cues (breadcrumbs, back arrows) inside the PageTitle component. Those belong above it in the layout hierarchy." />
</DosDonts>

<DosDonts>
  <Do description="Limit control actions to 2–3 primary operations. Secondary actions should be positioned within the page content." />
  <Dont description="Overcrowd the component with too many actions or metadata fields — it should establish hierarchy, not serve as a toolbar." />
</DosDonts>

## Code

### Title + Subtitle + 2 Button Controls

```tsx
import { PageTitle } from '@/components/ui/page-title'
import { PencilSimpleIcon, TrashIcon } from '@phosphor-icons/react'

<PageTitle
  title="Northeast Quarter"
  subtitle="Master list for Northeast Quarter"
  actions={
    <>
      <button><PencilSimpleIcon size={16} weight="thin" /> Edit List</button>
      <button><TrashIcon size={16} weight="thin" /> Delete List</button>
    </>
  }
/>
```

## Accessibility

- The title renders as an `<h2>` — there should be only one PageTitle per page.
- The chip is decorative text inside a `<span>`; if dismissible, the dismiss button has an `aria-label`.
- Actions passed via the `actions` slot should be accessible buttons or links with visible labels.
- Use chips to indicate content type or status only when the categorization aids understanding — they should not be the only method of conveying critical information.
